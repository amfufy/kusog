# Kusog Fit Quest

Offline, installable fat-loss tracker. Put all six files in the root of a GitHub repo and turn on GitHub Pages.

Files: index.html, manifest.json, sw.js, icon-192.png, icon-512.png, apple-touch-icon.png

When you change index.html later, open sw.js and bump VERSION (kusog-v1 -> kusog-v2) so phones pick up the update.
