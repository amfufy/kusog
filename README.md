# Kusog Fit Quest

Offline, installable fat-loss tracker with a 3D idle hero game. Upload ALL of these files to the root of the GitHub repo:

index.html, app.js, scene.js, combat.js, three.module.min.js, sw.js, manifest.json,
chakra-400.woff2, chakra-600.woff2, chakra-700.woff2,
icon-192.png, icon-512.png, apple-touch-icon.png

When you change any file later, open sw.js and bump VERSION (kusog-v6 -> kusog-v7) so phones pick up the update.
